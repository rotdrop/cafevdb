Detailed Description

The tos-app is desirable something like this is probably needed for legal reasons but it has only very limited support to define exception.

But it opens one possibility to by-pass its checks: if the PHP session-variable "term_uuid" contains the configured app-config value term_uuid then all checks are bypassed. One use case is to host mailing-list messages in the cloud and just publically share those with the mailing list server.

So the idea is to maintain an enhanced set of exceptions and if remote ip and or access path / service matches an exception then just place the term_uuid in the PHP session and be good.
