Detailed Description

SepaBankAccount.

In principle the IBAN field would be a perfect ID-field. However, it is stored salted and encrypted and thus cannot be used for queries. Instead, we use a simple integer sequence which is unique in connection with the musician id.

Note that a unique constraint is not possible as long as we store the personal data encrypted in the data base.
