Detailed Description

Apply all unapplied migrations one by one.

In contrast to the stock "migrations:migrate" command this does not use "all-or-nothing" for the complete set, as structural (non-transactional) and content (transactional) migrations must not be mixed in one run.

Output depends on the verbosity:

  • quiet: nothing
  • normal: one line per applied migration, errors
  • verbose (-v): additionally a summary table after the run
  • very verbose (-vv): additionally a summary table before the run
