◆ usage()

usage ( string|ParticipationContext $participationContext = ParticipationContext::UNRESTRICTED)

Return the number of "serious" items which "use" this entity.

For project participant this includces the number of payments. In the long run: only open payments/receivables should count.

If a participation context is given the usage in incremented by the number of instruments/roles configured for the complementary context.
