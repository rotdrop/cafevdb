Detailed Description

A wrapper around a given IMAP library in order to hide which one actually is used.

This is quite simplistic and only supports the things needed by the email form, i.e. copying messages, searching for a given message-id and retrieving messages in order to keep the SentEmails table consistent with the IMAP server
