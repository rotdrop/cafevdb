svgFromFile ( File  $file,
int  $options = self::SVG_OPTIMIZE,
?string  $hash = null 
)

Generate SVG image data from a given file.

If the content of $file is not already an SVG image, then try to generate a pixel image from $file and wrap the resulting image into an SVG-tag. If $file already contains SVG data then optionally try to optimize it and return the optimized SVG, as specified by $options.

Parameters
File$file
int$optionsConversion options, defaults to self::SVG_OPTIMIZE.
