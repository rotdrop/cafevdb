Detailed Description

Transliterate any given name into an ASCII login name.

In principle the Symfony AsciiSlugger does all this, but unfortunately also replaces all non-[a-zA-Z0-9] characters by the separator.

Generate a login-name from given unicode natural names.

Spaces will be converted

Parameters
array$namesFirst-, nick- and sur-name. The nick-name is optional and may be empty or even omitted.
[
'firstName' => UTF_8_FIRSTNAME,
'nickName' => UTF_8_NICKNAME,
'surName' => UTF_8_SURNAME,
]

The keys are actually arbitrary.

array$preferredThe preferred kyes into $names to use for slugging. These will be used if they are present. If not, then the remaining present keys are used.
string$separatorThe outer separator between the components of $names.
string$wordSeparatorThe "inner" separator which will replace sequences of white space.
Returns
string An ASCII only no-spaces slug suitable to be used as login-name.
