◆ configureAnnouncementsList()

configureAnnouncementsList ( string $listId,
?string $displayName = null,
$owners = [],
$moderators = [],
$posters = [] )

Configure the given list as an announcements-only list.

That is:

  • all postings are moderated
  • allow_list_posts set to false (no list-post header)
  • unsubscription is done without needing further confirmation from the user
  • subscription is unmoderated, but after user confirmation
  • $posters are added as list-members with the privilege to post to the list
  • the archive is public
Parameters
string$listIdThe list-id or FQDN. If a list-fqdn, then an additional query is needed to retrieve the list-id from the server.
null | string$displayNameIf given the display name of the list. If \null the display name remains unchanged.
string | array$ownersArray of owners or the single owner as string.
string | array$moderatorsArray of moderators or the single moderator as string.
string | array$postersArray of posters or the single posters as string. "posters" are the email addresses which are allowed to post to the list without moderation.
Returns
void
