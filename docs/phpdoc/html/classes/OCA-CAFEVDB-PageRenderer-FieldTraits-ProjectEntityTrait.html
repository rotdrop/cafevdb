EntityManagerTrait.php : 157

Removes an entity instance.

protected remove(mixed $entity[, bool $flush = false ][, bool $hard = false ][, bool $soft = false ][, bool $useTransaction = false ]) : void

A removed entity will be removed from the database at or before transaction commit or as a result of the flush operation.

Parameters
$entity : mixed

The entity instance to remove.

$flush : bool = false

Initiate a flush if true.

$hard : bool = false

Issue a double remove: if $entity is managed by Gedmo\SoftDeleteable then this will "hard" (read: finally) delete the entity unless it is tagged as "in use" by other means.

$soft : bool = false

For entities managed by Gedmo\SoftDeleteable first check if this entity is already tagged as "soft deleted" and if so do nothing.

$useTransaction : bool = false

Wrap the remove operation into a transaction or not. This parameter is ignored if $flush is false.
