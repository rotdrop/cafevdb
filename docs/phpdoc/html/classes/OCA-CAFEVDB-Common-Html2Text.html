HTML_CONVERTERS

Html2Text.php : 59
private array HTML_CONVERTERS = ['w3m' => ['-dump', '-I', 'utf-8', '-O', 'utf-8', '-T', 'text/html']]

List of possible html to text programs. Only w3m is supported as its output has proven to be the best for tables, block quotes and preformatted text, in contrast to the various PHP implementations of html2text which all are loosing when it comes to tables. lynx and elinks have been dropped as their output differs substantially from w3m.

None of the external programs seems to have support for CSS ... Oops.
