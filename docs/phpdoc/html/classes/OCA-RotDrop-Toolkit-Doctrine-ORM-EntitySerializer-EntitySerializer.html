EntitySerializer
in package
  • cafevdb
uses LoggerTrait

EntitySerializer.php : 47

The goal is to serialize entities (... to JSON ...) such that the JS frontend can reconstruct the association structure without duplicated data. For now this is meant for read-only access. "serialize" in this context means to compute a flat loop-free array representation which can then be safely fed into json_serialize.
