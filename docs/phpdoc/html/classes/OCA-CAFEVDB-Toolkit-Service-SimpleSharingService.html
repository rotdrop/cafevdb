linkShare()

SimpleSharingService.php : 89

Create a link-share for the given file-system node. If the node is already shared with the requested permissions then just return the old share.

public linkShare(Node $node[, null|string $shareOwner = null ][, int $sharePerms = Constants::PERMISSION_CREATE ][, null|false|DateTimeInterface $expirationDate = null ][, null|false|string $password = null ][, bool $noCreate = false ][, null|string $newShareOwner = null ]) : null|array<string|int, mixed>
Parameters
$node : Node

The cloud file-system node which shall be shared.

$shareOwner : null|string = null

User-id of the owner.

$sharePerms : int = Constants::PERMISSION_CREATE

Permissions for the link. Defaults to PERMISSION_CREATE.

$expirationDate : null|false|DateTimeInterface = null

Optional expiration date for the link. If null then create a link which does not expire. If \false then just ignore the expiration date. Otherwise do an exact match on the given date. Default to null.

$password : null|false|string = null

Optional password. If \false ignore, if null create a passwordless share. The share password is updated even if $noCreate is \true.

$noCreate : bool = false

Do not create a new share, but return an existing share if it exists.

$newShareOwner : null|string = null

If given try to modify the share to use the new owner. The share-owner is corrected event if $noCreate is \true.

Return values
null|array<string|int, mixed> —

The absolute URLs for the share or null.

[ 'files_sharing': URL, 'webdav' => DAV_URL, 'share' => ISHARE_INSTANCE ]
