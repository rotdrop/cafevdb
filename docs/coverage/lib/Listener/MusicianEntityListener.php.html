41/**
42 * An entity listener. The task is to manage changes in user-id and email
43 * addresses.
44 *
45 * When the user-id changes:
46 * - rename all file-system entries
47 * - update the RowAccessToken entity
48 *
49 * When the email adresses change
50 * - update the mailing-list subscriptions to use the current principal email
51 *   address
52 * - add new email addresses as passive subscriptions (no message delivery)
53 * - remove all obsolete email addresses from the mailing list subscriptions
54 * -
55 */
